# Project Constitution

## Project Defaults

| Setting | Project Default |
|---|---|
| Workflow Preset | agile-hybrid |
| Cost tracking mode | Lightweight |
| Control cycle cadence | Weekly, plus one extra cycle in the week before the event |
| Cost variance escalation threshold | 10% |
| Risk acceptance score ceiling | 8 |

## Team Working Rules

1. Any commitment that carries a deposit or cancellation fee needs the Sponsor's sign-off first.
2. Status reports go to the Sponsor every week, even when nothing changed.

## Project Working Rules

1. The event date is fixed once the venue is booked; scope flexes before the date does.
2. Nothing that costs money is committed without the Sponsor's sign-off.
3. Every attendee's dietary and access needs are recorded before catering is confirmed.

- Marta Silva (Sponsor)

## Escalation Rules

A deviation becomes a Change Request when it moves a milestone date, changes the headcount the
venue is booked for, or changes the budget by more than the escalation threshold. Anything smaller is absorbed and
noted in the tracker.

## Project Completion Criteria

The offsite has run, feedback is collected, the wrap-up note is sent, and every vendor is paid
or has a closing note.
