# Project Organization

## Governance Structure

| Body / Role | Purpose | Members | Decision Rights | Cadence |
|---|---|---|---|---|
| Sponsor | Funds the project and signs off baselines | Marta Silva | Scope, schedule, and budget changes; any spend commitment | Weekly status report |
| Project Manager | Coordinates work, runs the weekly control cycle, keeps the plan honest | Project Manager agent | Recommends; does not decide | Weekly |
| Change Control Authority | Approves or rejects Change Requests | Marta Silva | Approve, reject, or defer any CR | As needed |
| Event Lead | Owns day-to-day delivery and accepts finished work | Priya Nair | Accepts work packages; accepts risks scored 8 or below | Weekly |

**Escalation path:** team member to Event Lead, Event Lead to Sponsor. Anything that moves the
event date or the budget goes to the Sponsor within one working day.
