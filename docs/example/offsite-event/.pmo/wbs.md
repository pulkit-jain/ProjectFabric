# Work Breakdown Structure (WBS)

## Hierarchy

1. Venue and catering
   1.1 Select and book venue
   1.2 Confirm catering and dietary needs
2. Programme and content
   2.1 Draft two-day agenda
   2.2 Draft invitation and reminder emails
   2.3 Book workshop facilitator
3. Attendees and travel
   3.1 Collect attendance and dietary responses
   3.2 Arrange travel and rooms
4. Event delivery and close
   4.1 Run the offsite
   4.2 Collect feedback and write the wrap-up

## WBS Dictionary

| WBS ID | Name | Description | Deliverable | Acceptance Criteria | Owner |
|---|---|---|---|---|---|
| 1.1 | Select and book venue | Shortlist three venues, compare price and availability, get Sponsor sign-off, book | Venue and catering | A signed booking for the event dates, within the budget share agreed with the Sponsor | priya-nair |
| 1.2 | Confirm catering and dietary needs | Agree the menu with the venue and pass on the dietary list | Venue and catering | A written menu confirmation that covers every recorded dietary need | lakeside-venue |
| 2.1 | Draft two-day agenda | Draft a session-by-session agenda for both days | Programme and content | An agenda with timings for both days, approved by the Event Lead | agenda-agent |
| 2.2 | Draft invitation and reminder emails | Write the invitation, two reminders, and the dietary form text | Programme and content | Three emails approved by the Event Lead, with the dietary form linked | agenda-agent |
| 2.3 | Book workshop facilitator | Find and book someone to run the day-2 priorities workshop | Programme and content | A confirmed booking with a written fee within the Sponsor-approved amount | priya-nair |
| 3.1 | Collect attendance and dietary responses | Chase replies and keep the attendance list current | Attendees and travel | A reply from every one of the 40 invitees, with dietary needs recorded | tom-becker |
| 3.2 | Arrange travel and rooms | Book train tickets and rooms for everyone who needs them | Attendees and travel | Every attending person has a confirmed ticket and, if needed, a room | tom-becker |
| 4.1 | Run the offsite | Run both days on site | Event delivery and close | Both days held as per the agenda, with the priority list agreed at the end of day 2 | priya-nair |
| 4.2 | Collect feedback and write the wrap-up | Send the survey and write the wrap-up note with the priority list | Event delivery and close | Survey sent within two days, wrap-up note sent within one week of the event | agenda-agent |
